# Contributing to Nuro-SLAM

Nuro-SLAM is an experimental research platform for
neuromorphic and multi-robot SLAM.

## Contribution Areas

- Event-based SLAM integration and validation
- Reproducible benchmarks and dataset tooling
- Neuromorphic processing and acceleration
- Multi-robot mapping and collaboration
- Documentation and cross-platform portability

## Before Contributing

1. Review the relevant algorithm documentation.
2. Identify whether the change affects imported upstream code.
3. Preserve original authorship and attribution.
4. Document platform and dependency requirements.
5. Avoid committing datasets, credentials or build artifacts.

## Development Workflow

1. Create a dedicated Git branch.
2. Keep changes focused and reviewable.
3. Document the purpose and limitations of each change.
4. Run available builds and tests.
5. Record commands, results and known failures.
6. Submit changes for review before integration.

## Research Reproducibility

For experimental contributions, report:

- Git revision and operating environment
- Dataset provenance and checksums
- Calibration and timestamp conventions
- Algorithm configuration and parameters
- Evaluation methodology and metrics
- Runtime logs and known limitations

Do not equate compilation success with scientific validity.

## Upstream Algorithms

CMax, EROAM, EMBA and EPBA originate from independent
research projects. Preserve their authorship, citations
and applicable notices when modifying imported code.

## Review and Integration

Contributions should be reviewed for correctness,
reproducibility and compatibility with project goals.

Acceptance is not guaranteed.
