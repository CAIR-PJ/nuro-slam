# Nuro-SLAM

Neuromorphic SLAM Research Platform

Research repository for event-based SLAM ports, cross-platform toolchains, reproducible benchmarks, neuromorphic computing, and collaborative multi-robot mapping.

## Initial ports

CMax, EROAM, EMBA, and EPBA. Source imports will follow a provenance and licensing review.

## Research integrity

Numerical objective reduction does not establish independent trajectory or mapping accuracy.

## Status

Phase 1: independent repository scaffold only. No existing workspace files are copied.
