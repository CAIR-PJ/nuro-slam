# Security Policy

## Project Status

Nuro-SLAM is experimental research software.

It has not undergone a comprehensive security audit
and is not intended for safety-critical deployment.

## Reporting Vulnerabilities

Do not disclose exploitable vulnerabilities, credentials
or sensitive deployment information in public issues.

If the repository hosting service provides a private
vulnerability-reporting mechanism, use that mechanism.

Otherwise, contact the project maintainers through a
previously established private communication channel.

No dedicated security-response address or response-time
commitment has been established.

## Scope

Potential issues include:

- Unsafe handling of event-stream or dataset inputs
- Dependency and build-chain vulnerabilities
- Unintended exposure of credentials or sensitive files
- Network or ROS 2 interface security weaknesses

## Deployment Warning

Do not deploy this experimental code in autonomous
safety-critical systems without independent validation,
security assessment and appropriate safeguards.
